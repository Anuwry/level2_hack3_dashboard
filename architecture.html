f1 · Mic
Audio RMS Peak
How loud the impact is — raw amplitude of the crack
f2 · Mic ★ primary
Spectral Centroid
Brightness of sound. Sweet spot → high centroid (bright crack). Frame hit → low centroid (dull thud).
f3 · Mic ★ primary
Decay Time
How long ringing lasts. Sweet spot → short decay (energy into shuttle). Frame → long ringing (energy in frame).
f4 · Mic
Zero-Crossing Rate
Frequency proxy, cheap on M4F. Secondary noise flag for gym ambient sound.
f5 · IMU
Accel Magnitude Peak
Power transfer at contact. √(ax²+ay²+az²) — rotation-invariant. Set ±16 g range (smashes exceed 8 g).
f6 · IMU
Gyro Magnitude Peak
Wrist snap and swing rotation quality. √(gx²+gy²+gz²) — separates a clean contact with weak swing from strong swing with bad contact.
3-Class Rule Classifier (UNO Q · classifier.py)
# Explainable rule logic — constants tuned on court IF f3 (decay) > DECAY_LONG AND f2 (centroid) < CENT_LOW: → FRAME-LIKE HIT dull, long ringing = energy trapped in racket frame ELIF f2 (centroid) > CENT_HIGH AND f3 (decay) < DECAY_SHORT AND f5 (accel) > ACCEL_MIN: → SWEET SPOT bright, clean, strong transfer = energy into shuttle ELSE: → OFF SWEET SPOT intermediate — partial energy transfer

17 Biomechanical Joints
Hips Spine1 Spine2 Neck Head RightArm RightForeArm RightHand ×4 LeftArm LeftForeArm LeftHand RightUpLeg RightLeg RightFoot LeftUpLeg LeftLeg LeftFoot

Hips = 0 weight (always [0,0,0] after normalization). Spine1 = 0 weight (near-origin). RightHand = 4× weight (most critical for stroke technique).

Pose Matching Algorithms
1. normalizePose(kp)
Center at Hips=[0,0,0]. Scale = distance(Hips→Neck). Result: body-size and camera-distance independent coordinates.
2. poseSimilarity(a, b, weights)
Both pre-normalized. Returns 1 / (1 + Σ(dist×w)/Σ(w)). Range 0–1. Stroke-specific weights: RightHand=4×, Arm=3×, Hips/Spine1=0.
3. matchLabelsToFrames — Best-Any-Frame
Each session frame → score vs ALL label poses → take best. Speed-invariant matching. Group consecutive hits → event centered on peak-score frame.
4. computeStrokeAlignment — DTW
M×N cost matrix: dtw[i][j] = (1−sim) + min(diag, up, left). Traceback → monotonic path → sessionToLabel Map (O(1) lookup). Prefers JS normalization over Python 5dp-rounded sequence for bit-exact self-match.

Impact frame
= max wrist velocity (frame-to-frame Euclidean distance of RightHand)
Backswing Peak
= min elbow angle before impact (arm most bent — angle at RightForeArm joint)
Backswing Start
= last local max of elbow angle before backswing peak (arm starts to fold)
Follow-Through End
= first frame after impact where velocity < 20% of max velocity

Both signals Gaussian-smoothed (w=2) before detection. No hardcoded frame counts — purely signal-driven, works at any FPS.

Critical Risks & Mitigations
⚠ 3.3V I/O — Nano NOT 5V tolerant
All connections verified 3.3V. No piezo. No direct 5V signal. Permanent damage if violated.
⚠ Mount shift → invalid IMU data
Foam lining + athletic tape. Re-test after every remount. Any looseness measures mount vibration, not racket motion.
⚠ BLE is stretch goal only
USB Serial primary. BLE attempted only after USB Serial demo is stable end-to-end. BLE is never a dependency.
⚠ Thresholds not yet tuned
Collect 180+ labeled hits on court first. Tune constants in classifier.py. Never tune at desk.
ℹ Pose Z-depth less accurate than X,Y
MediaPipe infers depth from 2D priors — can jump 10–15 cm during fast strokes. Kalman filter smooths this. Use normalized body-relative coords for scoring.
ℹ UNO Q boot ~30 s
Dashboard auto-starts as systemd service. Know exact boot time before demo. Prepare graceful "booting…" state on dashboard.
